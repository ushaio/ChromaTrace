# 工作区与缩略图栏 V1

## 目标

把现有单图修图流程升级为可跨会话恢复的单当前工作区批量修图流程：用户可一次导入多张图片，按来源卷选择复制或直接引用，在缩略图栏切换图片，并将每张图片的调色参数独立保存。

## 需求范围

1. 在现有资料库根目录下实现 `workspaces/default/manifest.json`、`originals/`、`references/`、`thumbs/` 的持久化布局。
2. 实现 manifest 的版本、revision、原子替换和容错读取；图片身份使用 `volumeId + relativeSourcePath`，不使用盘符或内容哈希。
3. 在 Rust 侧实现来源卷判定、卷挂载解析、卷策略记忆、复制/引用导入、逐条落盘、取消和崩溃恢复所需的数据接口。
4. RAW 缩略图优先使用 rawler 内嵌预览，失败时回落现有完整解码；普通图片和缩略图缓存走现有二进制 IPC。
5. 在前端增加工作区类型、命令封装、工作区加载/保存与 `effectiveReference` 解析、缩略图键和并发加载工具。
6. 将 `reference` 提升为工作区级属性，将 adjustments、fineTuneVisibility、matchRenderMode、modelStyle 下沉为当前图片的 develop 数据；切换图片不丢参数。
7. 增加固定高度的 Filmstrip：单选切换、选中高亮、RAW/状态/已修/专属参考角标、键盘导航、Ctrl/Shift 多选和“套用当前配方到所选”。
8. 增加多文件导入确认 UI：按卷展示复制/引用选择、重复导入提示、目标路径与空间信息、策略记忆、改判警告、后台进度和失败重试。
9. 增加卷缺席聚合提示和资料库设置中的卷策略记忆管理；清空工作区时清理 manifest 条目、副本和缩略图缓存。
10. 保持现有单图/AI 调色体验可用，浏览器环境提供内存 fallback，桌面环境走 Tauri IPC。

## 明确非目标

- 工作区管理器 UI（新建、切换、重命名）。
- 内容哈希去重、批量导出、批量删除、XMP sidecar 写回、缩略图拖拽排序。
- 预览区高度动画或缩略图栏自适应改变预览布局。
- 按需复制 deferred 状态；V1 采用确认后立即后台复制。

## 约束

- 现有未提交改动属于用户既有工作，不覆盖、不回滚。
- `LoadedImage` 继续只表示当前全解析图片；工作区列表不得常驻多个 HTMLImageElement。
- 缩略图栏固定高度，不触发预览框尺寸动画；共享 `source` 的两套工作区必须同步检查。
- Rust 命令沿用 `Result<T, String>` 与简体中文错误文案；前端 IPC 字段使用 camelCase。
- 包管理使用 npm，保留 package-lock.json，不使用 pnpm。

## 验收标准

- [ ] `npm run build` 通过，Vitest 通过；新增纯逻辑至少覆盖 thumbKey、effectiveReference、manifest 容错/冲突和批量套用。
- [ ] `cargo fmt -- --check` 与 `cargo test` 通过；工作区路径安全、引用模式不复制、复制模式大小一致、恢复状态逻辑有测试。
- [ ] 桌面端命令注册完整，浏览器 fallback 不因缺少 Tauri API 崩溃。
- [ ] 多选图片后能将当前图配方套用到所选，当前图不重复计算；切换后各图参数独立保留。
- [ ] Filmstrip 固定高度、可键盘导航、可显示状态角标，并在选中变化时滚动到可见范围。
- [ ] 导入 UI 明确显示复制副本的真实目标路径、空间预检和引用风险；缺席卷按卷聚合提示而非逐张弹窗。
- [ ] 清空工作区能清理工作区副本与缩略图缓存，并显示可回收空间。

## 实施备注

按 P0 → P1 → P2 顺序实现；如果现有 UI 结构不适合一次性替换，优先抽出纯逻辑和独立组件，再以最小 props 接入 App.tsx。
